## 处理、图片与费用

所有文章沿用正文提取、模型分析、公开投影与事件归组；被预筛排除的文章保留在库，不冒充公开可见。正文 HTML 与图片继续使用 `body_html`、`media` 和图片代理缓存，没有新增图片表，也没有 OCR。

模型批次先遇到供应商限流和 Windows 进度文件替换错误，现已修复原子保存的有界重试、在途任务收口、限流暂停和串行归组，并降低分析并发。结果未知的请求受原有回执规则保护；正常恢复会复用已有响应，超过保护时间只允许按既有机制放行一次。不得把“已采集”写成“所有文章已处理”。实时快照可运行：

```powershell
node --env-file=.data/wechat-first-batch/local.env .data/wechat-all-sources/report.mjs
```
