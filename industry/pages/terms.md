页首说明：

> 本站聚合东南大学各单位公开信源，用模型生成中文摘要与精选，原文版权归各来源单位所有。网站、RSS、公开 API 与 MCP 均可匿名使用。

## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有误，重要信息（报名时间、资格条件、截止时间等）请务必以原文为准。原文版权归各来源单位所有；站内只在来源允许时展示全文，其余只展示摘要和原文链接。

## 2. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式，请通过反馈页联系我们，我们会尽快处理。

## 3. 使用本站的数据

欢迎你为个人阅读、学习和班级/社团内部转告使用本站内容。以下用途需要事先取得我们同意：商业产品中使用、公开转载批量内容、以任何形式再分发本站数据、绕过频率限制批量抓取。

## 4. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口。请按响应中的缓存时间轮询，遇到 429 请遵守 Retry-After，不要并发重试。

## 5. 账号与投稿

登录和社团组织投稿需使用真实身份。不得利用本站发布违法违规、虚假、广告或侵害他人权益的内容；运营方有权删除违规内容并停用相关账号的投稿权限。

## 6. 免责

本站按"现状"提供，不保证内容完整、准确和持续可用。因学校官方通知调整、信源页面变动等原因导致的信息偏差，请以官方渠道为准。
