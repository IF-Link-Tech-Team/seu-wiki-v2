
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：部门名 / 学院名 / 活动名 / 项目名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是口号 / 节令 / 没信息量的 teaser（如 "重要通知"、"等你来"、"新学期新气象"）时，结合【来源】和正文把主体补进标题。例：原标题 "重要通知" + 来源 "教务处" + 正文讲改选 → "教务处发布改选通知"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体部门或活动时，用上位词（如"校内通知"）兜底，绝不凭"常识"编一个具体部门、学院或时间。
5. 原标题表达的【文章类型和核心动作】是硬边界：攻略 / 解读 / 经验 / 盘点类标题，中文标题必须保留这个类型；不能因为正文提到一则已经存在的通知或安排，就改写成“发布 / 官宣 / 上线”。只有原标题明确宣布了发布、公示或开启报名，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的部门、学院、活动名。
   例：原标题 "保送研究生全流程经验分享" → "保研全流程经验分享"，不能写成 "研究生院发布推免通知"。
   例：原标题 "一文看懂选课系统" + 来源和正文明确是教务处 → "教务处选课系统使用指南"，不能只写成缺主体的 "一文看懂选课系统"。
